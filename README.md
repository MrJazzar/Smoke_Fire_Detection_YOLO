# Smoke & Fire Detection using YOLO 🔥🚨

## 📌 Project Overview
This project focuses on detecting **smoke and fire** in images and videos using the **YOLO (You Only Look Once)** object detection algorithm.
The system can be used for early fire detection in surveillance and safety systems.

## 🛠️ Technologies Used
- Python
- YOLO (v12)
- OpenCV
- PyTorch
- NumPy
- Matplotlib

## 📊 Dataset
- Labeled images containing fire and smoke
- Annotations in YOLO format
- Data augmentation applied to improve robustness

⚠️ Dataset is not included due to size limitations.

## 🧠 Model
- YOLO-based object detection model
- Classes:
  - Fire
  - Smoke
- Trained using transfer learning on pre-trained YOLO weights
